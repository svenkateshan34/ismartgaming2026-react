# iSmart Gaming — Premium React Website

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open the project folder in VS Code.
4. Run:
   npm install
   npm run dev
5. Open the local URL shown by Vite (usually http://localhost:5173).

## Build for hosting
npm run build

Upload the generated `dist` folder to Netlify, or import this project into Vercel.

## Customize
- `src/App.jsx`: player name, Instagram URL, text, stats and highlight links.
- `src/styles.css`: colors, animations, layout and visual theme.
- Replace the placeholder stats (`--`) with your actual game details.
- The central futuristic character is built with CSS shapes and 3D transforms; no external character image is required.

The page is a fan-made player portfolio and is not affiliated with PUBG or BGMI.
